# Quantum Physics

A mobile application prototype for collecting, visualizing, and exploring
data from smartphone sensors.

## Overview

Quantum Physics is an experimental mobile application that uses smartphone
sensors as a lightweight data collection environment.

The project explores how a smartphone can be used to collect physical
measurements, visualize sensor data, and organize observations into a
format that can be reviewed and analyzed.

Despite its name, this application is a sensor-data collection and
visualization experiment. It is not a quantum mechanics simulation engine.

## Features

The application is designed around the following capabilities:

- Smartphone sensor data collection.
- Recording physical measurements such as acceleration.
- Exploring gravity-related sensor readings where supported by the device.
- Graphical visualization of collected measurements.
- Organizing collected data for further inspection.
- PDF report or data export functionality, subject to the capabilities
  implemented in the current version.

Actual sensor availability and measurement behavior depend on the
smartphone hardware and operating system.

## Project Status

**Status: Experimental prototype**

The application has been tested on a physical smartphone.

Its functionality, measurement accuracy, export behavior, and compatibility
with other devices require further testing before it can be considered a
validated scientific measurement tool.

## Scientific Limitations

Smartphone sensors are useful for demonstrations, experiments, and
exploratory data collection. However, their readings should not
automatically be treated as laboratory-grade measurements.

Important considerations include:

- Sensor calibration and measurement uncertainty.
- Differences between smartphone models.
- Sampling frequency and measurement resolution.
- Coordinate systems and device orientation.
- Sensor noise and environmental influences.
- The distinction between raw acceleration and gravity-compensated data.

Results should be compared against suitable reference instruments when
measurement accuracy is important.
